# ตารางงานรายเดือน (PWA) – ขั้นตอนนำขึ้นใช้งาน

## ไฟล์ในชุดนี้
- `index.html` – ตัวแอป
- `manifest.webmanifest` – ชื่อ/ไอคอน/โหมดเต็มจอของแอป
- `sw.js` – ทำให้ใช้งานออฟไลน์ได้
- `icons/` – ไอคอนแอป (192, 512, maskable, apple-touch)

ต้องอัปโหลดทุกไฟล์ **โดยคงโครงสร้างโฟลเดอร์เดิม** (ให้ `index.html` อยู่ระดับบนสุด)

---

## วิธีที่ 1: Netlify (ง่ายที่สุด ลากวางได้เลย)
1. แตกไฟล์ ZIP ให้ได้โฟลเดอร์ `schedule-app`
2. เข้า https://app.netlify.com/drop แล้วสมัคร/ล็อกอิน (ฟรี)
3. ลากโฟลเดอร์ `schedule-app` ไปวางในหน้าเว็บ
4. รอสักครู่จะได้ลิงก์รูปแบบ `https://ชื่อสุ่ม.netlify.app`
5. (ไม่บังคับ) ไปที่ Site configuration → Change site name เพื่อตั้งชื่อลิงก์ให้จำง่าย

## วิธีที่ 2: Cloudflare Pages
1. สมัคร/ล็อกอินที่ https://dash.cloudflare.com
2. ไปที่ Workers & Pages → Create → Pages → Upload assets
3. ตั้งชื่อโปรเจกต์ แล้วลากโฟลเดอร์ `schedule-app` (หรือไฟล์ทั้งหมด) ไปวาง
4. กด Deploy จะได้ลิงก์ `https://ชื่อโปรเจกต์.pages.dev`

## วิธีที่ 3: GitHub Pages
1. สร้าง repository ใหม่บน GitHub (ตั้งเป็น Public)
2. กด Add file → Upload files แล้วอัปโหลดทุกไฟล์รวมโฟลเดอร์ `icons`
3. ไปที่ Settings → Pages → Source เลือก Deploy from a branch → `main` / `(root)` → Save
4. รอ 1–2 นาที ลิงก์จะเป็น `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

> ต้องเป็นลิงก์ `https://` เท่านั้น (ทั้ง 3 วิธีข้างบนเป็น https อยู่แล้ว) ระบบติดตั้งแอปและออฟไลน์จึงจะทำงาน

## วิธีให้ผู้ใช้ติดตั้งแอป
**iPhone / iPad (Safari เท่านั้น)**
1. เปิดลิงก์ด้วย Safari
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น)
3. เลือก "เพิ่มไปยังหน้าจอโฮม" → "เพิ่ม"

**Android (Chrome)**
1. เปิดลิงก์ด้วย Chrome
2. กดเมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"

**คอมพิวเตอร์ (Chrome / Edge)**
- กดไอคอนติดตั้งที่ปลายแถบที่อยู่ หรือเมนู → "ติดตั้ง ตารางงานรายเดือน"

แจกลิงก์หรือสร้าง QR code จากลิงก์ให้ผู้ใช้สแกนได้เลย

---

## การอัปเดตแอปในอนาคต
1. แก้ไฟล์ แล้ว **เปลี่ยนเลขใน `sw.js`** บรรทัด `const CACHE = 'schedule-v1'` เป็น `schedule-v2`, `v3`, ...
2. อัปโหลดไฟล์ที่แก้ทับของเดิม
3. ผู้ใช้เปิดแอป 1–2 ครั้งจะได้เวอร์ชันใหม่

## เรื่องข้อมูล
- ข้อมูลเก็บในเครื่องของผู้ใช้แต่ละคน ไม่ปะปนกัน และไม่ซิงก์ข้ามเครื่อง
- ถ้าล้างข้อมูลเบราว์เซอร์หรือลบแอป ข้อมูลจะหาย
- ใช้ปุ่ม **💾 สำรอง** เพื่อบันทึกเป็นไฟล์ `.json` และ **📂 กู้คืน** เพื่อนำกลับมา (การกู้คืนจะแทนที่ข้อมูลปัจจุบันทั้งหมด) ใช้ย้ายข้อมูลระหว่างเครื่องได้ด้วย
